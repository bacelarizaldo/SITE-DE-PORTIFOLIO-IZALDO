# 3. POSICIONAMENTO

A IB Films deve ser posicionada como uma produtora audiovisual independente que transforma ideias, marcas, pessoas e eventos em conteúdo audiovisual profissional.

O site deve fugir completamente da aparência de:

- freelancer genérico;
- fotógrafo de baixo custo;
- "fazemos seu vídeo";
- agência de marketing genérica;
- site cheio de textos corporativos;
- portfólio com dezenas de trabalhos sem curadoria.

Quero que o visitante pense:

"Esse cara sabe produzir imagem."

"Esse trabalho tem qualidade."

"Eu gostaria que minha empresa/marca/evento tivesse essa aparência."

O site precisa vender **percepção de valor antes de vender preço**.

Não quero colocar uma tabela de preços como elemento principal do site.

---

# 4. OBJETIVO PRINCIPAL DO SITE

O objetivo principal do site é gerar novos clientes.

O visitante deve conseguir:

1. entender rapidamente quem sou;
2. visualizar a qualidade do meu trabalho;
3. entender o que eu faço;
4. identificar que posso atender o tipo de projeto dele;
5. conhecer alguns projetos relevantes;
6. sentir confiança;
7. entrar em contato comigo.

O site deve funcionar como uma espécie de vendedor silencioso da IB Films.

A prioridade é:

**Impacto visual → percepção de qualidade → confiança → portfólio → serviço → contato.**
